# Lernpfad Bank

Trainings-App für die IHK-Abschlussprüfung Bankkaufmann (AO 2020): Lernfelder, Karteikarten, Quiz, Rechenaufgaben, Prüfungssimulation.

**App öffnen:** https://wilhelmwege1-hub.github.io/lernpfad-bank/

## Als App installieren
- **iPhone/iPad:** Link in Safari öffnen → Teilen → *Zum Home-Bildschirm*
- **Mac:** Link in Safari öffnen → Ablage → *Zum Dock hinzufügen* (oder in Chrome: Installieren-Symbol in der Adresszeile)

Nach dem ersten Öffnen läuft die App auch offline. Der Lernstand bleibt auf dem jeweiligen Gerät gespeichert.
